## Stack

- **Framework** — Next.js (App Router)
- **Styling** — Tailwind CSS v4
- **UI** — shadcn/ui, Lucide icons
- **Analytics** — Vercel Analytics

## Running locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
